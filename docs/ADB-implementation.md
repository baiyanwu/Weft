# ADB 配置与内置工具实施计划

**目标：** 用户明确指定的 ADB 优先；没有指定时自动扫描；扫描没有可用版本时使用应用内置版本。指定版本失效时提示，不自动切换。

**设计：** 在通用设置增加同风格的 ADB 卡片，展示来源、路径、版本和错误；支持选择文件、手动填写路径、重新扫描和恢复自动。后台验证 `adb version`，避免阻塞窗口。已有设备连接统一使用解析后的路径，切换路径后释放鼠标、重新发现并连接设备，不终止系统 ADB 服务。

**文件：** 解析及验证放在 `Sources/Weft/Services/ADBResolver.swift` 和 `ADB.swift`；持久化与扫描状态放在同目录 `ADBConfiguration.swift`；设置卡片放在已有 Views 目录。ADB 和完整第三方声明直接放在已有 Assets 目录。Xcode 将 ADB 作为签名辅助程序复制进应用。
