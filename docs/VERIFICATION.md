# 验证范围

## 设备与行为

当前真实设备验证集中于 OnePlus OPD2413 平板和 Seeker 手机，系统均为 Android 16 / API 36。历史记录包含 USB 连接、多设备排列和跨屏检查；不同版本的修改不代表所有场景均重复验收。

0.2.0 build 31 的 Seeker 鼠标点击与按住拖动已由使用者确认；该轮平板尚未重新连接加载同一修复。Wi-Fi 配对和连接入口已经实现，但无线延迟、网络变化、不同厂商和更早 Android 版本没有完整验证。

没有把 macOS 13 最低构建目标等同于全版本运行验收。通用二进制可同时包含 arm64 / x86_64，但 Intel 的构建成功也不代表已在 Intel 硬件运行验证。

## 自动检查

仓库包含 Swift 坐标、布局、会话、连接重试、设备删除与鼠标捕获检查，以及 Android 坐标解析和鼠标报告检查。Xcode 的 Build / Archive 仅编译；Test 操作和 GitHub CI 执行主机检查。设备操作脚本需要主动选择并明确指定设备，不会由 CI 自动运行。

开源打包整理不自动启动或重连应用，不操作实体设备，不将历史功能检查冒充本轮回归。打包和签名检查关注编译、架构、资源、签名、Apple 公证、Gatekeeper 和校验值；实际跨屏与按键效果由使用者另行验收。

## 已知限制

- Android 使用授权的 ADB shell、`/dev/uhid` 和非公开系统接口；坐标诊断也依赖内部格式。
- macOS 后台光标控制包含非公开接口，未来系统可能改变行为。
- 当前仅支持 Mac ↔ 每台 Android；Android 设备之间通过 Mac 切换。
- 不共享键盘、音视频或剪贴板。游戏独占输入和特殊页面需要单独验证。
- 默认开发包和 GitHub 测试包为 ad-hoc 签名、未公证；正式安装包必须另行使用本机 Developer ID 签名并通过公证。

私人原始日志、设备标识和开发记录不包含在公开仓库中。
